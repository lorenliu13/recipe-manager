# Recipe Manager / 食谱管理

A bilingual recipe collection in English and Chinese.
中英双语食谱合集。

## Structure / 结构

Each recipe is saved as a `.md` file. Filename format: `recipe-name.md` (use hyphens, lowercase).

每个食谱保存为一个 `.md` 文件。文件名格式：`菜名.md`（可用中文或英文命名）。

## Recipe Template / 食谱模板

See `_template.md` for the standard format.
请参考 `_template.md` 了解标准格式。
