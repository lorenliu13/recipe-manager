# Candidate Recipes / 待选食谱

This folder holds generated recipe drafts for review.
Once approved, move the file to the appropriate regional folder under `recipes/`.

此文件夹存放待审阅的食谱草稿。
确认后，将文件移动到 `recipes/` 下对应的地区文件夹中。

## Workflow / 流程

1. New recipe drafts are saved here / 新食谱草稿保存于此
2. Review the recipe / 审阅食谱
3. If approved → move to `recipes/<region>/` / 满意后移入对应地区文件夹
4. If rejected → delete the file / 不满意则删除文件
